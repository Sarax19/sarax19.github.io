# sarax19.github.io

Personal site of Sara Fernández. Plain HTML and CSS, served by GitHub Pages.

- `index.html`: the whole page. Edit the text here.
- `style.css`: styles.
- `img/`: photo, SG[Spain] team poster, favicon and the Open Graph image (`og.png`) used when the link is shared.
- No CV is published. To add one later, put `cv.pdf` in the root and add `<a class="btn" href="cv.pdf">Download CV</a>` to the `.actions` links in `index.html`.

To change something: edit the file, commit and push from GitHub Desktop. The site updates in one or two minutes.
